# The Frog Frontier brand kit

Everything needed to rebuild the site in the new look.

- `README.md`: the brand guide. Read this first.
- `tokens.css`: colors, spacing, radii and type as CSS variables. `tokens.json` is the same data.
- `components/bundle.css`: the component styles (classes start with `ff-`).
- `components/<Name>/README.md` and `preview.html`: each component's rules and an example.
- `assets/`: the logo frog, leaves, grain texture and reference images.

Note: the `preview.html` files point at images by an online id (`/_blob/...`). In your own project, use the matching file in `assets/` instead.

## Prompt to paste into the other project

> Rebuild my site, frogfrontier.com, using the attached Frog Frontier brand kit. Read README.md first and follow it exactly. Load tokens.css and components/bundle.css, and the three Google fonts named in the README. Use the Hero at the top of the home page, SectionTitle for each section, ProductCard for products and Button for every action. Use only the colors, fonts and assets in the kit. Keep all existing page content and links; change only the design.
