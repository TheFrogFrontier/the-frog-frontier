# Logo
`frog-teal.png` is the logo frog, converted to teal halftone ink on a transparent ground. Use it on the yellow disc, blended with `mix-blend-mode: multiply`. `frog-pencil-original.png` is the original graphite drawing it was made from; keep it as the master and do not use it on the site. Never recolor the frog, flip it, outline it or place it on pink.
