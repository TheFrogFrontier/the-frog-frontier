# RisoDisc
Flat ink circles that mix where they overlap. This is the brand's signature shape: yellow over pink prints orange, yellow over green prints a deeper green.

- Wrap the group in `ff-riso` (it sets `isolation: isolate`), then add `ff-disc` plus `ff-disc--yellow`, `--pink`, `--green` or `--teal`.
- Size each disc with `width`; it stays round.
- The logo pairing is fixed: a large yellow disc, the teal frog on it, and a pink disc about 40% of the size overlapping the lower right.
- Keep to three discs in a group. Text never sits on pink or green.
- Add `ff-grain` to the wrapper for the speckled print texture.
- You provide: sizes and positions.
