# Stamp
A pink rubber-stamp label, tilted slightly, for one playful line.

- Class: `ff-stamp`. Uppercase, Fredoka Bold, 24px or larger so the pink stays legible.
- Use once per page at most. It carries a joke or a notice, never navigation.
- On packaging it prints smaller; on screen keep it at 24px or above.
- You provide: the words. Keep it under five.
