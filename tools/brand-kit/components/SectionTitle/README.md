# SectionTitle
A teal heading with a short pink bar beneath it, and an optional script line above.

- Classes: `ff-title` on the heading, `ff-title--center` to center it, `ff-eyebrow` on the line above.
- The eyebrow is Sriracha and stays short: "Plate I", "Est. 2026", "New this week".
- Use one per section. Headings are sentence case except the shop name, which is uppercase.
- You provide: the heading text and level (`h1` to `h3`).
